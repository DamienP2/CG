Pulse CG Server

Ce programme installe le serveur d'habillage broadcast Pulse CG :

  • l'exécutable cg-server dans /usr/local/pulse-cg ;
  • un service système (launchd) qui démarre automatiquement au boot ;
  • les données dans /Library/Application Support/PulseCG.

Une mise à jour conserve les templates, le rundown et les médias existants.
